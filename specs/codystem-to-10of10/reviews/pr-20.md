# Independent review — PR #20 (feat/10of10-c2, C2 seeded-bug harness)

**Diff reviewed:** `origin/main..HEAD` (C2a: `src/review-score.ts` + tests + CLI + harness workflow +
first-run corpus/verdicts/report/ANALYSIS).

**Method:** a single independent adversarial reviewer (Sonnet, different model from the Opus author),
instructed to run the code and construct concrete failing inputs. It mutation-tested key claims.

**Outcome:** NEEDS-FIX — 3 major, 2 minor, plus explicit confirmation that the core scoring math,
the `pass`-gate direction, abstention-as-miss, and the ledger honesty are correct.

## Findings and resolutions

1. **(major) Duplicate case ids double-counted.** `score()` iterated all cases without dedup, so two
   cases sharing an id credited one verdict as two catches/FPs — an integrity hole in a *measurement*
   tool. *Fixed:* dedup by id (first wins), surface `duplicateIds`, and make it a hard `pass=false`
   integrity failure. Proof: t-cs8.

2. **(major) FP-gate boundary untested.** A mutant `fpRatePct <= maxFpPct` (10% would wrongly pass)
   survived all tests — they only exercised 0% and 12.5%. Code was correct; coverage wasn't. *Fixed:*
   t-cs7 pins exactly 10% → fail.

3. **(major, honesty) The corpus had duplicated code, undisclosed.** `k5`==`k17` (byte-identical
   `fetchWithRetry`) and `k23` a rename — so the "retry throws undefined" edge case was one issue
   counted three times, inflating the raw FP (6/11) and the apparent breadth. *Fixed:* the harness now
   de-dupes by normalized code, the byte-duplicate was dropped from the committed corpus (→ 26 cases,
   **5/10 FP**), and ANALYSIS.md now discloses the correction and describes the retry pattern as the
   single edge case it is.

4. **(minor) Verdicts matching no case were silently dropped.** *Fixed:* `unmatchedVerdicts` is now
   surfaced with a reason (stale/mismatched corpus). Proof: t-cs9.

5. **(minor) The report CLI crashed on a malformed JSONL line** despite being "report-only." *Fixed:*
   `parseJsonl` skips malformed lines and warns, never throws.

Confirmed CORRECT by the reviewer (ran, not just read): catch-rate/FP math, `pass` gate direction,
abstention-as-miss (t-cs5 kills the mutant), empty-corpus handling, `pct` rounding, and ledger
honesty (parent C2 stays `[ ]`; C2a states the raw unflattering numbers; C2b defers the hard part).
