## Findings and resolutions

1. **(blocker) `version.ts` — a re-tagged/garbage version was accepted as a safe no-op.** The regex
   `^v?(\d+)\.(\d+)\.(\d+)` was unanchored and dropped prerelease/build tags, so
   `checkUpgrade("1.2.3", "1.2.3-evil-rollback", …)` returned `{ok:true}` — defeating the guard's
   purpose. *Fixed:* anchored, tag-capturing regex (rejects trailing garbage / a 4th component); a
   no-op now requires the FULL version to match, and a same-core different-tag string is refused as
   ambiguous. Proof: t-ver1 (anchored/reject), t-ver7 (rollback refused).
2. **(major) `tenant.ts` — cross-tenant collision on a case-insensitive filesystem.** `("Repo","Actor")`
   and `("repo","actor")` produced distinct keys but the same on-disk dir on macOS APFS — a verified
   read-back leak. *Fixed:* segments are lowercase-canonicalized, so those are deliberately ONE
   tenant (consistent on every FS). Proof: t-tn6.
3. **(minor) `readFlips` threw on a truncated trailing line** (crash mid-append). *Fixed:* skip a
   partial/corrupt line rather than discard the whole ledger.
4. **(minor) `ops.ts` dedup key was a flat namespace** — two different gates sharing a `sig` collided.
   *Fixed:* the key is namespaced by gate (`gate/sig`). Proof: t-ops8.
5. **(minor) `failureRate(_, 0)` fell back to the whole series.** *Fixed:* `lastN<=0` → empty window
   → 0. Proof: t-ops9.

Confirmed CORRECT by the reviewer: `validSegment` traversal rejection (`..`, encoded dots, NUL,
fullwidth lookalikes), O_APPEND concurrency (100 concurrent processes, loss=0 leak=0), onset/dedup/
re-arm alert logic, provenance-loss detection, onboard.sh exit-14 path, and the "10/10 not yet
proven / Phase E not run" honesty in QUICKSTART/tasks.
