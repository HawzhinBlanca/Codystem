**Method:** a multi-agent adversarial review run as a workflow. Five reviewers (Sonnet, `effort:
high`), one per lens — red-team logic, enforcement/security, test rigor, shell/CI portability,

the actual code. A finding survived only with ≥1 CONFIRMED and CONFIRMED ≥ REFUTED. This satisfies
BLUEPRINT step 4's "independent (different-model) review of the diff": the author is Opus; every
reviewer/verifier ran on a different model.

**Outcome:** `mergeable: false` on first pass — **6 confirmed major defects, 0 dismissed**. All were

## Findings (all CONFIRMED by 2 different-model verifiers) and resolutions

1. **`hunt.mjs` — `expect:'allow'` never checked the guard.** The classifier counted any non-`block`
   expectation as "caught" unconditionally, so it could not detect an over-block regression (or
   verify any allow-path). *Fixed:* `expect:'allow'` now consults the guard — allowed → caught,
   blocked → `OVERBLOCK` (reds, exit 1). Proof: `src/redteam.test.ts` t-rt8/t-rt9.

2, 4, 5, 6. **`anticheat-scan.sh` — D1 env-skip detector defeated by indirection.** A variable alias
   (`const ci = process.env.CI; if (ci) return`), bracket notation, ternary, multi-line split, and
   Python `os.environ`/`os.getenv` all evaded the literal-only grep, so the exact cheat D1 claims to
   close survived a clean checkout — and the D1 `[x]` + "14/14" claim overstated coverage. *Fixed:*
   the detector now strips whitespace (defeats multi-line) and matches every env-access form for the
   CI/GITHUB_ACTIONS/CONTINUOUS_INTEGRATION tokens, with a boundary so `process.env.CITY` is not a
   false positive. Proof: `src/anticheat.test.ts` (alias/bracket/ternary/multiline/python all flag;
   CITY stays clean; the repo's own tests stay clean), reliability corpus now 16/16.

3. **`surface-integrity.sh` — silent abort on a missing enforcement file.** `[[ -f ]] && sha` on the
   last file, under `set -euo pipefail` + the `| sort` pipeline, aborted the whole script with no
   diagnostic and wrote a truncated manifest — and silently skipping a missing file is a deletion
   blindspot. *Fixed:* a `require_all_present` preflight fails loudly (exit 11) on any absence, in
   both `--write` and check modes. Proof: `src/surface-integrity.test.ts` t-surf5.
