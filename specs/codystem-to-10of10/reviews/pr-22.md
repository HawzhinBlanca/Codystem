   ruled out). Proof: t-rev9.
2. **(blocker) Self-forgery regex was EOL-anchored.** `Reviewed-by: me obviously` slipped past.
   *Fixed:* the placeholder (me/self/author/the author/…) is matched as a token, not anchored to
   end-of-line. Proof: t-rev10.

   because "opus" is a substring. *Fixed:* whole-word model extraction (split on non-alphanumerics,
   match exactly). Proof: t-rev11.
4. **(major) findings-gate severity was case-sensitive.** `"severity":"Blocker"` skipped the gate.
   *Fixed:* severity normalized with `ascii_downcase` in jq. Proof: t-fg7.
5. **(major) None of the four bypasses were tested.** *Fixed:* regression tests added for each (the
   tests above), so CI now guards these.
